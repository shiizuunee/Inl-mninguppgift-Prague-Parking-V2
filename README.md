# Inlämninguppgift Prague Parking V2

## Projekt Information
Detta repository innehåller två versioner av Prague Parking systemet:

- **PragueParking2.0** - G-nivå version
- **PragueParking2.1** - VG-nivå version

## Hur man kör programmet

### För VG (version 2.1):
1. Öppna solution i Visual Studio
2. Högerklicka på **PragueParking2.1** → "Set as Startup Project"
3. Tryck F5 eller Ctrl+F5

### För G (version 2.0):
1. Öppna solution i Visual Studio
2. Högerklicka på **PragueParking2.0** → "Set as Startup Project"
3. Tryck F5 eller Ctrl+F5

## Testdata
Testdata genereras automatiskt vid första körningen.
