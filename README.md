# Object-Oriented Parking Management System – Prague Parking

## Overview

This project involved creating an object-oriented parking management system for Prague’s parking facility with a capacity of 100 vehicles. The system handles four vehicle types: cars, motorcycles, bicycles, and buses, each with different sizes and pricing.

I developed two versions:  
- **Version 2.0 (Basic / G-level):** Core OOP functionality with JSON persistence  
- **Version 2.1 (Advanced / VG-level):** Added interfaces, extended vehicle types (bicycle and bus), bus restrictions, and dynamic configuration management  

The project resulted in a fully functional console application with a professional user interface using **Spectre.Console**.

## Features

- Supports cars, motorcycles, bicycles, and buses  
- Different sizes and pricing for each vehicle type  
- Core OOP design with classes and interfaces  
- JSON persistence for storing parking data  
- Bus restrictions and rules for proper parking management  
- Dynamic configuration management for flexibility  
- Professional console UI using Spectre.Console  

## Technologies Used

- **Language:** C#  
- **Application Type:** Console application  
- **UI Library:** Spectre.Console  
- **Data Persistence:** JSON files  
- **Version Control:** Git & GitHub
